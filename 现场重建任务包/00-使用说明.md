# 00 · 使用说明（现场重建任务包）

> 本任务包的目标：让一个**新的 OpenClaw 会话**在**空目录**中，按《02-分阶段执行提示词.md》逐段实现「餐饮门店 · 交付契约台」的**完整、可运行的核心功能**，并逐段验收。
> 本包**不修改**既有成品、**不启动**重建、**不继续扩展**功能。是否开工（彩排 / 现场）由人工确认后另行发起。

---

## 1 · 它是什么、不是什么

- **来源**：基于**赛前已有的原型与设计**——冻结版快照（`_freeze-20260928/`）与验收资料（`_accept-20260928/`），均位于**本任务包的上一级目录**（本项目目录内），供人工核对。本包是**文档与测试预期**，不含可运行的成品代码。
- **是什么**：六段可粘贴提示词 + 产品规格 + 测试场景与预期 + 执行/故障手册 + 演示稿。
- **不是什么**：
  - 不是「把旧快照的 48 个文件搬一遍」——**重建目标是完整、可运行的核心功能**，不是文件数量；
  - 不是自动脚本——需要人把提示词**逐段**交给 OpenClaw 执行；
  - 不是像素级复刻旧界面——行为由测试覆盖，视觉按《04》的人工清单过目。

## 3 · 怎么用（顺序）

1. 读《01-产品与验收规格.md》：确认「要建什么、验收看什么」。
2. 开工：把《02-分阶段执行提示词.md》**一次复制一段**给 OpenClaw；上一段验收通过，再给下一段。
3. 测试：用《03-合成材料与测试预期.md》的场景逐条做。
4. 过程管理：《04-现场执行与故障备选.md》（启动 / 检查 / 存档 / 失败切换 / 时间不够时的取舍）。
5. 演示：《05-三分钟演示稿.md》。
6. **空目录重建彩排：等人工确认后再做**（本包不自动开始）。

## 4 · 工具 / 运行环境 / 依赖 / 模型配置

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11（在 Windows 11 上实测） |
| Python | **3.10 以上**（3.12 实测） |
| 依赖 | **仅 streamlit**（固定版本，见 `requirements.txt`；国内建议清华源安装） |
| 网络 | 不联网也能完整跑完；**联网时多两项能力**：材料抽取、把结论说成人话 |
| 磁盘 | 约 100 MB |
| 浏览器 | 系统浏览器或 Chrome；演示前把系统缩放调回 100% |

**模型配置（可选，占位示例；真实配置由本机环境提供）：**

```
# .env.local（占位示例——不要把真实密钥写进任何文档、对话或截图）
OPENAI_API_KEY=<在此填入本机密钥>
OPENAI_BASE_URL=<可选：OpenAI 兼容端点地址>
OPENAI_MODEL=<可选：模型名>
```

**密钥纪律**：不读取、不复制、不在对话里透露真实密钥；密钥不进任务包、不进截图、不进聊天记录；模板文件只含占位符。

**端口**：重建版使用**独立端口**，避开现有服务（例如冻结版使用的 8501）——启动前先探测，实际端口记入《进度与变更记录》（详见《04》）。

## 7 · 红线（全流程适用）

1. **不改动当前运行中的版本**；不启动 / 停止现有服务；不占用其端口。
2. **不读取、不复制真实密钥**；密钥只由本机环境提供。
3. 一切**合成**、**预跑**内容必须如实标注；**不把复制或预跑成果描述成「现场原创」或「实时生成」**。
4. **不伪造开发时间**（不虚构耗时、提交时间）。
5. **不声称视觉已验收**；助手无法查看图像时，不得给出视觉结论（留给人工）。
6. 结论必须**可复算、有出处**；缺证据时不许承诺（「证据不够，敢说停」是产品的一部分）。
