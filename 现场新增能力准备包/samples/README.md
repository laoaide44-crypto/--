# samples/ · 合成测试数据说明

> **性质：赛前准备的合成功能测试材料，不代表真实门店经营情况。**
> 全部门店与员工均为**虚构**（`S-01/S-02`、`E-xxx`），**不含任何真实客户数据**。
> 用途：为「排班表导入 / 校验 / 工时计算 / 证据更新」准备**小规模、可人工复算**的测试输入。
> **状态：计划 / 尚未实施** —— 这些是**测试输入与算术预期**，不是「应用功能已验收」的结果。
> 行号口径：**表头 = 第 1 行**，第一条数据 = 第 2 行。

## 逐文件预期（合计与定位）

| 文件 | 小计 / 结论 | 关键预期 |
|---|---|---|
| `SYNTHETIC_VALID_two_stores.csv` | **1800 分 = 30.00 小时**（无阻断 / 无重叠 → 「文件内已解析记录工时合计」，并列声明 / 实含 / 完整性） | 分员工 E-001 14.00 / E-002 4.00 / E-003 8.00 / E-004 4.00；分门店 S-01 18.00 / S-02 12.00；覆盖 8/3–8/5 |
| `SYNTHETIC_ERRORS_mixed.csv` | **660 分 = 11.00 小时（「无异常记录小计」，不得应用为完整基线）** | 阻断行号 = **3,4,5,6,7**；有效行 = 2、8；**存在阻断 → 不替换原基线** |
| `SYNTHETIC_DUPLICATE_row.csv` | **660 分 = 11.00 小时** | 重复行 = **行 3**（**已处理的数据质量提示**；保留行号映射，去重计一次，显示去重影响 18.00h→11.00h） |
| `SYNTHETIC_OVERLAP_cross_store.csv` | **不应用**（整体被阻断）；仅行 4 可作「无异常记录小计」7.00h | 行 2 与行 3（E-301，跨门店）→ **未解决冲突**；**不再给 14.00h 结论**，也不得直接相加当工时 |
| `SYNTHETIC_PARTIAL_coverage.csv` | **1260 分 = 21.00 小时（「文件内已解析记录工时合计」，并列范围 / 完整性未确认）** | 仅 S-01、仅 8/3–8/4；有缺口，**缺记录不按零**，**不外推** |
| `SYNTHETIC_TEXT_INJECTION.csv` | **660 分 = 11.00 小时** | 阻断行 = **行 3**；行 2 文本仅作数据，**不执行** |

> **汇总纪律**：无阻断 / 无未解决重叠 → 给「**文件内已解析记录工时合计**」+ 声明范围 / 实含范围 / **完整性是否已确认**（**合计 ≠ 范围完整**，不得称「客户全部工时」、不得替换更大范围基线）；有阻断或未解决重叠 → 只给「**无异常记录小计**」，不得应用为完整基线；**禁止用区间并集消解重叠**；没记录的日期 / 门店**不按零**。完全重复属**已处理的数据质量提示**（去重计一次、保留行号、显示影响）。
>
> 对照口径示例：若对 `SYNTHETIC_VALID_two_stores.csv` 用户自报「同范围 33 小时」→ 可比 → 差异 -3.00h；
> 若自报是「实际考勤 26 小时」→ **口径不同（计划 vs 考勤）→ 不可直接比较**。

- 全部数字可用上表「净工时(分)」逐行相加后 ÷60 复核；**算术预期正确 ≠ 应用功能已验收**（功能尚未实现）。
- 本目录样本**不得**被描述为真实客户证据或真实试点结果；文件名一律 `SYNTHETIC_` 前缀，页面与导出须同步保留演示标识。
- **来源与状态分开记**：来源**沿用现有枚举**（客户内部材料存 `INTERNAL`、界面显示「客户内部」；未确认显示「未确认」，**不得默认 `INTERNAL`**）；`INTERNAL` **只描述来源，不代表真实性或效果已验证**；**合成标识独立存储、优先显著展示**，**合成材料不得**因「模拟内部排班表」就呈现为真实客户内部证据；用户确认应用只表示采用版本，**不升级**为已验证事实。
- 不使用真实姓名 / 手机号 / 身份证 / 工资等个人敏感字段；`staff_id` 仅为匿名标识。
