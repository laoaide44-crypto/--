## 第一段 · CSV 导入与确定性校验

**开始前需要读取的资料**
- 《02·CSV字段与计算口径》§1–§4、§8；《03》用例 **A / B / D / J**；`samples/README.md`；`samples/SYNTHETIC_VALID_two_stores.csv`、`SYNTHETIC_ERRORS_mixed.csv`、`SYNTHETIC_DUPLICATE_row.csv`、`SYNTHETIC_PARTIAL_coverage.csv`、`SYNTHETIC_TEXT_INJECTION.csv`。
- 现有 `app.py` 的「丢材料 / 上传文件」入口与 `screen` 状态机（了解插入点，勿改其既有语义）。

**本段范围**
- 只做：**入口选择 → 读文件 → 认表头 → 字段级校验 → 记录级校验（重复/重叠）→ 产出结构化结果、问题清单与校验状态**。
- 不做：工时汇总与版本（留给第二 / 三段）；不做 Excel/OCR。

**要交付的可运行行为**
1. 在**现有上传入口**内提供**显式选择**：「作为文本分析」/「作为排班表校验」；仅后者走结构化路径，且**不把整份文件自动发给模型**；
2. 接受 `.csv`（UTF-8，容忍 BOM），按 §1 解析；
3. 表头校验：缺列 / 列名不符 → **整文件阻断**（E6）；未知列 → 提示（W3）；
4. 逐行逐字段校验，输出**行号 + 字段 + 规则编号 + 值**，严格按 §4：
   - 阻断 E1 空值 / E2 解析失败 / E3 结束≤开始 / E4 负休息 / E5 休息≥班次长度 / E7 标识非法；
   - 提示 W1 完全重复（**保留行号映射**，仅计一次）/ W2 同员工（含跨门店）非完全重复重叠 → **未解决冲突** / W4 时区偏移不一致；
5. 产出**校验状态**（待校验 / 有阻断问题 / 结构校验通过）；分别记录「用户声明范围」与「文件实含范围」，缺口标注 W5，**缺记录不按零**；
6. **不设法律/行业阈值**；不把任何文本当作指令执行。

**验收用例**：《03》A（0 阻断）、B（阻断行恰为 `3,4,5,6,7`；重复行标记且不计）、D（缺口清单）、J（行 3 解析失败阻断、行 2 文本仅作数据）。

**失败时的定位方法**
- 行号对不上：核对「表头 = 第 1 行」口径（§1）；
- 阻断/提示混淆：回查 §4 分级表逐条比对；
- 编码乱码：先查 BOM 与 UTF-8 解码；
- 中文逗号误判分隔：确认仅英文逗号作分隔、引号字段按 CSV 规则解析。

**完成条件**
- A / B / D / J 的**校验部分**全部符合，且输出可精确指向行号与字段；
- 问题清单可导出（文本即可），与《03》预期逐条对齐；
- 未改动既有功能语义，样本文件未被修改。

## 第二段 · 有效数据预览、工时汇总、来源回指及口径比较

**开始前需要读取的资料**
- 《02》§5–§9（计算口径 / 重叠 / 范围覆盖 / 可比性）；《03》用例 **A / C / D / E / F**。
- 第一段产出的结构化结果与问题清单。

**本段范围**
- 只在**有效数据**上：预览、算表内计划工时、回指来源、做口径比较。
- 不做：用户确认与版本（第三段）；不判定冗余/合理编制/节省。

**要交付的可运行行为**
1. **预览**：逐行净工时（分钟为中间单位，展示保留 2 位小数），带来源回指（行号 + 字段）；
2. **汇总**：严格按 §5.2——无阻断 / 无未解决重叠 → 给「**文件内已解析记录工时合计**」+ 声明范围 / 实含范围 / **完整性是否已确认**；否则只给「**无异常记录小计**」：
   - **完全重复**：属**已处理的数据质量提示**；保留行号映射、去重计一次、**显示去重数量及对工时的影响**（确认前用户可见）；
   - **非完全重复的同员工重叠（含跨门店）**：列为**未解决冲突**，**不合并 / 不去重 / 不并集**；
   - **存在阻断或未解决冲突 → 只给「无异常记录小计」、不得应用为完整基线、不替换原基线**；可存**待处理草稿**；
   - **不得**用「区间并集」消解重叠；
3. **范围与覆盖**：展示声明范围、文件实含范围、缺口与**完整性是否已确认**（§8）；**缺记录不按零**；声明「完整」与程序核对**分别保留**；
4. **口径比较**：按 §9 四维核对；一致 → 给差异，且**只有范围与口径一致才可比较或替换对应部分**；不一致 → 明确「**不可直接比较**」；
   - 排班计划 ≠ 实际考勤 → 不可直接比较；
   - 一周结果不外推全年；
5. **保留历史**：自报与原始假设**并存**，不被覆盖。

**验收用例**：《03》A（**文件内已解析记录工时合计 30.00h**，并列声明 / 实含 / 完整性；分员工 E-001/2/3/4 = 14/4/8/4、分门店 S-01/2 = 18/12）、B（重复 = 已处理提示，去重后 11.00h 且显示去重影响）、C（**未解决冲突 → 阻断应用**、**无 14.00h 结论**、可存草稿）、D（**合计 21.00h** + 范围 / 完整性 + 缺口清单、不外推、缺记录不按零）、E（30.00 vs 33.00，差 -3.00h，保留自报）、F（出现「不可直接比较」，无差额数字）。

**失败时的定位方法**
- 合计偏差：用 `samples/README.md` 逐行分钟数核对；检查是否把阻断行 / 重复行计入；
- 重叠漏判：核对 `start_a < end_b 且 start_b < end_a`（首尾相接不算）；
- 跨午夜算成负值：确认用完整日期时间相减（§3）；
- 「可比」误判：逐维回查 §9 四维；
- 误用并集：确认重叠**只列未解决冲突**，**没有**用区间并集或自动去重生成合计。

**完成条件**
- A / C / D / E / F 的**汇总与比较部分**全部符合；
- 每个结论数字都能**回指到具体行**，且可人工复算；
- 存在阻断或未解决冲突时**只给「无异常记录小计」**；合计均并列显示声明范围 / 实含范围 / 完整性是否已确认；去重处理结果在确认前可见；
- 无「外推」「冗余认定」「法律阈值」类越界表述。

## 第三段 · 用户确认应用、证据版本、判断更新、撤回与导出一致性

**开始前需要读取的资料**
- 《01》§3 用户流程与 §5 复用位置；《02》§10；《03》用例 **G / H / I**。
- 现有证据更新与撤回机制（合成情景的 apply / undo）与其**变化报告结构**（前 / 后 / 依据）——**复用模式，勿重写**。

**本段范围**
- 用户**确认**后：把计算结果作为**新证据版本**，重算判断与草案，支持切换 / 撤回 / 导出。
- **确认是显式动作**；模型不得代为确认或决定升级。

**要交付的可运行行为**
1. **确认应用**：仅在用户显式确认后，将结果作为**证据版本 vN** 进入事实记录；**一次确认应用 = 一个证据版本**，记录**文件哈希 / 解析与校验规则版本 / 用户声明范围 / 文件实含范围 / 来源与合成标识与确认状态 / 计算结果及前一版本引用**；
2. **变化报告**：逐条「之前 / 之后 / 依据」（依据 = 行号 + 字段），并列出旧结论失效；
3. **重算**：判断 / 试点范围 / 草案走**同一计算链**；导入结果**不自动升级**证据门槛（口径不一致时明确不得升级）；
4. **各维状态分别标注**（来源沿用现有枚举：客户内部材料存 `INTERNAL`、界面显示「客户内部」；来源未确认显示「未确认」、**不得默认 `INTERNAL`**；材料性质 / 数据口径 / 校验状态 / 应用状态）；**合成标识独立存储、优先显著展示**，**不得**把合成呈现为真实客户内部证据；用户确认应用只表示采用版本，**不升级**为已验证事实；
5. **版本切换**：门店 / 日期筛选是**版本内视图**（不拆版本）；同一文件覆盖范围或解释变化 → 新版本；可切换 v1 / v2，页面与导出同步；
6. **撤回**：只恢复**上一证据版本及其派生结果**，干净复原、无残留，**不抹去历史**；
7. **导出一致性**：页面与导出**逐条一致**；合成标识在页面与导出各至少一处，不得只标一处。

（**草稿**：存在阻断或未解决冲突时，**只能存待处理草稿**，不得确认应用。）

**验收用例**：《03》G（一确认一版本 / 版本切换 / 撤回无残留且不抹历史）、H（来源枚举与「未确认」+ 合成标识独立且优先展示、贯穿页面与导出）、I（逐条一致）。

**失败时的定位方法**
- 撤回有残留：对照应用前的快照逐项比对（合计 / 状态 / 范围 / 报告）；
- 页面与导出不一致：四类对照（合计 / 分项 / 口径 / 标注）；
- 门槛被自动升级：回查门槛输入，确认未被导入结果静默置位；
- 版本串味：确认版本切换是「替换」而非「叠加」；
- 草稿被误应用：确认存在阻断 / 未解决冲突时**只能存草稿**，不能确认应用；
- 状态混同：确认「来源 / 材料性质 / 口径 / 校验 / 应用」**分开标注**；来源未确认显示「未确认」、**未默认 `INTERNAL`**；合成独立存储、优先展示。

**完成条件**
- G / H / I 全部符合；
- 每个版本都记录了**哈希与规则版本**；撤回后**无残留**且**历史版本仍可查**；页面与导出**逐条一致**；
- 全程未由模型决定算术或证据升级。
